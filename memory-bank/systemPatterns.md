# System Patterns

2026-07-14 - Memory Bank initialized.

## Coding Patterns

*   **Standalone HTML pages** — each tool is one self-contained `.html` file
*   **CSS custom properties** — dark theme variables
*   **Fetch API** — Jina Reader calls via client-side fetch()
*   **No build step** — vanilla HTML/CSS/JS

## Architectural Patterns

*   **Client-side API calls** — no server proxy, Jina called directly from browser
*   **Flat file structure** — `public/tool-name.html`
*   **Git-push deployment** — CF Pages auto-deploy

## Testing Patterns

*   Manual testing only
