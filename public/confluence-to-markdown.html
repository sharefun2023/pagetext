How to Export Confluence Pages to Markdown

There are several ways to get your Confluence content into Markdown. Here are the most effective methods:

Method 1: PageText Web Converter (Easiest)

Use the converter above. Export your Confluence page as HTML (via Browser → Save As or Space Tools → Export to HTML), then paste the HTML into the converter. Get clean Markdown instantly — no installs, no scripts.

Method 2: Confluence REST API

Fetch Confluence page content programmatically via the /rest/api/content/{id}?expand=body.storage endpoint. Pipe the storage format HTML through PageText's converter for automated workflows. Ideal for CI/CD pipelines and bulk migrations.

Method 3: Atlassian Marketplace Apps

Apps like "Markdown Exporter for Confluence" or "Scroll Markdown Exporter" integrate directly into Confluence. However, many are paid and require admin permissions. PageText is free and requires no Confluence admin access.

Method 4: Pandoc (Advanced)

Export Confluence to HTML, then run pandoc input.html -f html -t markdown -o output.md. Pandoc handles many edge cases but requires command-line setup. Use PageText for quick, no-setup conversions.
