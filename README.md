Paste a URL, get clean Markdown. Ideal for feeding web content into LLMs, note-taking apps, or archiving.

## What It Does

- Strips HTML, CSS, JS, nav bars, sidebars, ads
- Outputs clean, structured Markdown
- Preserves headings, lists, links, code blocks
- Powered by [Jina Reader](https://jina.ai/reader/) — handles JavaScript-rendered pages

## Use Cases

| Use Case | Why |
|----------|-----|
| **LLM context** | Feed clean article text into ChatGPT/Claude without token bloat |
| **Obsidian/Notion** | Archive blog posts as notes |
| **Research** | Collect sources without formatting chaos |
| **Readability** | Strip the junk — just the content |

## Quick Start

```
https://pagetext.io/?url=https://example.com/article
```

Or paste a URL on [pagetext.io](https://pagetext.io).

## Tech Stack

- Jina Reader API for content extraction
- Cloudflare Pages (global edge hosting)
- Minimal, zero-JS landing page except for conversion logic
